# Roof & More Website

Premium multi-page Roof & More Studio website built in a separate local folder.

## What Is Included

- Home, about, services, industry, project, resource, blog, contact and policy pages.
- Service pages for architecture, interiors, structural engineering, project management, construction management, industrial roofing, PEB buildings, and factory/warehouse solutions.
- Project-detail and blog-detail route systems.
- Roofing estimator, material comparison, roof color visualizer, site-visit and quotation form interfaces.
- Official Roof & More contact details, Indore office, Dubai office and locally downloaded official project images.
- Sitemap, robots metadata and route-level page metadata.

## Notes Before Launch

- Completed-project count is intentionally editable because the official website shows conflicting numbers.
- Testimonials, client names, project budgets, warranties, prices, licenses and technical specifications should be published only after Roof & More approves them.
- Forms are front-end ready. Connect email, CRM, secure file upload, spam protection and persistent storage before production launch.

## Scripts

- `npm run dev` starts the local preview.
- `npm run build` creates the production build.
- `npm run lint` runs ESLint.
